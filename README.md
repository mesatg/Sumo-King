👑 Sumo King

Sumo King is a Unity arcade-style survival game where the player controls a ball and tries to stay on the platform while facing increasingly difficult enemy waves.

Enemies attempt to push the player off the arena, and the goal is to survive as long as possible by controlling movement and collecting powerups that spawn around the platform.

🕹️ Gameplay Overview

The player controls a ball using WASD or Arrow Keys

Enemies spawn in waves, with the number of enemies increasing each round

Enemies try to knock the player off the platform

Powerups spawn around the arena to help the player survive

Falling off the platform results in game over

✨ Features

Wave-based enemy spawning system

Increasing difficulty over time

Arena-style survival gameplay

Collectible boosts and powerups

Simple and responsive player controls

🛠 Tech Stack

Engine: Unity

Language: C#

Input: Keyboard (WASD / Arrow Keys)

Platform: PC

🎯 Purpose

The purpose of this project is to practice core gameplay mechanics such as wave management, powerups, increasing difficulty, and player movement using Unity and C#.
